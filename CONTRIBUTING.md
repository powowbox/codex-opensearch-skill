# Contributing

Thank you for contributing.

1. Open an issue for substantial behavioral or security changes.
2. Create a focused branch and keep changes narrowly scoped.
3. Never include credentials, private endpoints, user-specific paths, or production data.
4. Add or update tests for behavioral changes.
5. Run `python3 -m unittest discover -s tests`, `ruff check .`, and `python3 -m build`.
6. Describe the security impact and validation in the pull request.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
