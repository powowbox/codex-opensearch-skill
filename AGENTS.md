# Repository instructions

- Keep the launcher dependency-free and compatible with Python 3.9 or later.
- Never add real endpoints, usernames, passwords, Keychain entries, or machine paths.
- Never print secrets or pass them through process arguments.
- Preserve the pinned upstream server version unless the change documents and tests the upgrade.
- Keep OpenSearch examples read-only and use placeholder values.
- Run unit tests, Ruff, package build, and secret-pattern checks before release.
